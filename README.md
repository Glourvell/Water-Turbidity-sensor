The sensor is the Turbidity Sensor
It has three pins 

PIN LAYOUT
1.VCC = 3.3V
2.OUT = OUT GPIO 34
3.GND = GND

The VCC is normally used with a 5v but since I lack the 5Kc and 10Kc resistors we have to use a low power voltage of 3 volts

The code also has a html file for displaying the water readings in a user friendly way
The page refreshes the readings after 1 second
